# PWA_basica - Aplicación Web Progresiva (PWA)

¡Felicidades! Este paquete contiene tu aplicación PWA lista para ser desplegada en cualquier servidor web HTTPS (Vercel, Netlify, GitHub Pages, Firebase Hosting, Cloud Storage, etc.).

## 📁 Archivos Incluidos
- `index.html`: Estructura principal de la aplicación.
- `styles.css`: Estilos CSS de la interfaz.
- `app.js`: Lógica de la aplicación y registro del Service Worker.
- `manifest.json`: Configuración de instalación para Google Chrome y Microsoft Edge.
- `sw.js`: Service Worker para soporte sin conexión (offline) y almacenamiento en caché.

## 🚀 Cómo instalar en Chrome / Edge
1. Sube estos archivos a un servidor web con **HTTPS**.
2. Abre la URL en **Google Chrome** o **Microsoft Edge** en tu PC, Mac o Android/iOS.
3. Haz clic en el icono de instalación ➕ en la barra de direcciones o en el menú "Instalar aplicación".

Generado con PWA Studio Builder.
